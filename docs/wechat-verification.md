# 微信开发者工具验证记录

日期：2026-10-16。工具版本：2.02.2608080，基础库：3.17.4，Windows。当前项目配置为 miniprogram，使用用户现有 AppID。

## 故障与修复

实际模拟器先前显示 WXML 编译失败：旧页面第4行的模板表达式被解析为非法值。项目已切换到小程序模式，因而没有进入根目录 game.js 对应的小游戏入口。此前基于小游戏 Canvas 的模拟测试没有覆盖这个实际入口问题。

小程序页面现已改为 Canvas 2D 宿主，与原生小游戏共用 utils/controller.js 和 utils/canvas-game.js。可交互区域由原生透明 view 与画面同步，通过 WXML bindtap 调用相应操作。渲染版本号避免过期点击落到新界面的错误按钮。Canvas 触摸和小游戏鼠标事件保留为兼容路径。

## 实际验证

通过微信开发者工具的 automation_element_action 点击页面中的原生 .native-hit 元素，随后用 automation_evaluate 读取真实小程序运行时结果。验证不是直接调用排序引擎代替点击。

- 页面完成编译和启动，loading=false，error 为空。
- 点击「选关」成功打开选关页，「返回游戏」回到棋盘。
- 第一关通过原生点击完成，steps=12，minimum=12，victory=true，stars=3。
- 第一关记录为 best=12、stars=3、clears=1，解锁位置为2。
- 点击「下一关」进入第二关，初始步数0。
- 点击来源和目标盒，第二关步数从0变1，撤销历史长度从0变1。
- 点击撤销，步数从1恢复到0，撤销历史长度回到0。
- 返回选关页，第一关显示三星和12步，第二关为进行中。见 wechat-runtime.png。

`node tests/run-all.js` 八组自动测试通过，另行覆盖100关最少步数的独立验证、最优三星通关、评分边界、旧成绩迁移、星级不降级、原生点击层和四种屏幕尺寸。

尚未执行手机真机验证。模拟器截屏工具无法完整捕获 Canvas GPU 图层，因此最终证据来自 Windows 上实际开发者工具窗口截图。
