# 百关版本设计与验收

用户已确认将首版扩展为100关，并增加选关页、通关记录与最佳步数。

## 关卡

1～10关从4色递进至6色，提供两个空盒；11～40关以6～7色混排为主；41～70关以一个空盒训练空间规划；71～100关以7～8色综合挑战为主。15、25等关卡减少颜色并恢复两个空盒，作为轻松关。每十关标记挑战关。所有盘面互不重复，每关最少步数已经精确求解并独立验证不存在更短解。运行时只加载 JavaScript 数据模块，不执行搜索。

## 选关和成绩

顶部保留帮助和选关入口，底部仍只有一排撤销、提示、重开按钮。选关页每页20关，共五页；显示锁定状态、当前关卡、已通关状态和最佳步数。通关解锁下一关。结算页提供下一关、查看关卡、重玩本关，当前有撤销历史时也允许撤销一步。

每关保存最佳步数及通关次数；同一次游玩撤销后再次完成不重复增加次数，但允许更新更优成绩。重玩本关重新计次，保留之前的最佳成绩。恢复已完成盘面不重复计次。第100关结束后可回到第一关重玩，不删除记录。

最少步数通关得三星，多1～5步得两星，其余成功通关得一星。结算显示本次星级，选关页根据最佳步数显示历史最高星级。旧成绩加载时按当前最少步数重新计算星级，不信任存档中的星数值。

## 双入口与点击

用户当前配置为 miniprogram，保留其 AppID；小程序通过 Canvas 2D 页面运行，绘制、玩法与原生小游戏 game.js 共用。小程序原生透明 view 与 Canvas 中所有操作区域同步，使用 bindtap 触发动作，并通过渲染版本号拒绝过期点击。小游戏使用触摸及鼠标事件，支持 clientX/clientY、pageX/pageY 和 x/y。

## 存档

使用本机存储 candy-sort-v3，分别保存每关盘面、步数、盘面签名、成绩和解锁位置。切换关卡保留草稿；返回或重启后恢复。撤销历史只在当前连续游玩期间有效。读取失败、非法关卡和损坏盘面回退到有效初始状态；初始盘面签名不匹配时重置该关盘面。迁移 v2 时保留当前关卡编号并解锁到该关，不迁移旧布局，不伪造历史成绩。

不使用震动。不引入广告、支付或云端账户。

## 验收结果

`node tests/run-all.js` 运行八组测试，覆盖100关唯一性、精确最少步数、星级边界及历史最高星级、输入兼容、点击移动与撤销、解锁及最佳成绩、独立草稿与损坏存档、旧版迁移、四种屏幕下布局、小程序 Canvas 宿主及原生点击区域。JS-only 加载器从真实 game.js 启动，通过模拟画布触控连续以最优步数三星通关100关，并验证关间跳转和最终成绩恢复。

浏览器辅助预览复用实际 Canvas 绘制代码，已检查游戏页、选关第一页及第81～100关页面，截图见 level-select-preview.png。浏览器预览和自动测试模拟微信 API，不能替代微信开发者工具与真机验收。
